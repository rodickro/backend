
## Tecnologías utilizadas

- Node.js
- Express
- MySQL
- JavaScript

## Instalación

1. Clonar el repositorio.
2. Instalar las dependencias:

   npm install express nodemon cors mysql morgan

## Configuración

Crear un archivo `.env` con las siguientes variables:

DB_HOST=
DB_PORT=
DB_USER=
DB_PASSWORD=
DB_NAME=

## Ejecución

npm run dev
